The first time you open it

Roomtone isn't signed by Apple or Microsoft yet, so your computer asks you to confirm the first time. That's expected, and you only do it once.

On a Mac

  1. Open Roomtone from Applications. macOS says it can't check the app. Click Done.
  2. Open System Settings › Privacy & Security and scroll to Security.
  3. Click Open Anyway next to the message about Roomtone, then Open, and confirm with your password or Touch ID.

Comfortable with Terminal? This one line removes the "downloaded from the internet" mark from Roomtone only:

xattr -dr com.apple.quarantine /Applications/Roomtone.app

On Windows

When SmartScreen says "Windows protected your PC", click More info, then Run anyway.

Allow it to find your speakers

Say Allow when asked to find devices on your local network. Without that, Roomtone can't see your speakers. On a Mac you can change it later in System Settings › Privacy & Security › Local Network.

No speakers nearby? Roomtone shows a demo system with made-up rooms so you can try everything.

Check your download

Every release lists a checksum for each file in SHA256SUMS. Put it in the same folder as your download and run:

shasum -a 256 -c --ignore-missing SHA256SUMS      # macOS
sha256sum -c --ignore-missing SHA256SUMS          # Linux

A line ending in OK means the file is exactly what the project published.

Build it yourself

Roomtone is open source (MIT or Apache 2.0). The README shows how to build it with Rust.
