Privacy

The short version: Roomtone doesn't track you, and neither does this website.

The app

  • No telemetry, no ads, no accounts of its own. Nothing is sent anywhere except your speakers, the music sources you use, the services you sign in to and, only if you switch Lyrics on, lrclib.net.
  • Your data stays on your computer. Settings, scenes, sign-ins, the assistant access key and your listening history are files in your user folder, readable only by you.
  • Looking for a new version is your choice. It's off until you switch it on. When on, Roomtone reads this project's latest release record from GitHub when it starts and then about once a day. The only thing that identifies the app is its normal User-Agent with the version number. A new version is downloaded only when you press Download, and nothing is installed for you.
  • The assistant link is off by default, with an access key, a look-only mode and a switch for each kind of change.
  • It works offline. You don't need the internet to control speakers on your own network.

The full list of network connections is in the project's specification (section 9), and the code is open for anyone to read.

This website

  • No cookies, no analytics, no advertising, no third-party fonts or scripts.
  • The download page asks GitHub which version is newest, so it can show the right file. GitHub can see your address when that happens, as it does when you visit any GitHub page. If that fails, the buttons simply go to the releases page.
  • Links to GitHub take you to GitHub, which has its own privacy policy.
