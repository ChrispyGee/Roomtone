# Microsoft Store listing text, by language

The English text is in [docs/MICROSOFT_STORE.md](../../../../docs/MICROSOFT_STORE.md). These are the translations for the other languages the package declares (`AppxManifest.xml`), made on 2026-11-23 and **not checked by a native speaker**. Search terms are comma-separated; the four screenshot captions are in the order home, player, scenes, light.

>
> • Alle Räume auf einem Bildschirm: Wiedergabe, Pause, Überspringen, Lautstärke und Gruppen, mit Ziehen und Ablegen.

> • Kostenlos und Open Source. Deine Daten bleiben auf deinem Computer.
